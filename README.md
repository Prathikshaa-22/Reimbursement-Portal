🧾 Reimbursement Portal
A full-stack web application to manage employee reimbursements, claims, and pre-approvals with role-based access for Employees and Managers.
🚀 Features
👤 Authentication
Secure login system
Role-based access (Employee / Manager)
Session handling using local storage
📄 Employee Features
Submit Claims with details and invoices
Create Pre-Approval Requests
View submitted claims & pre-approvals
Track status:
✅ Approved
❌ Rejected (with manager comment)
⏳ Pending
🧑‍💼 Manager Features
View Pending Claims & Pre-Approvals
Approve or Reject requests
Add comments during rejection
View approval history
Dashboard with:
Total pending claims
Total pending pre-approvals
🛠️ Tech Stack
Frontend
Angular (Standalone Components)
TypeScript
Bootstrap (UI Styling)
Backend
ASP.NET Core Web API
Entity Framework Core
Database
SQL Server
