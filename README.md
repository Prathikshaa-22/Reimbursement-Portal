# 🧾 Reimbursement Portal

A **full-stack web application** designed to manage **employee reimbursements, claims, and pre-approvals** with **secure role-based access** for Employees and Managers.

---

## 🚀 Features

### 👤 Authentication
- Secure login system
- Role-based access control:
  - **Employee**
  - **Manager**
- Session handling using **Local Storage**

---

### 📄 Employee Features
- Submit reimbursement **claims** with:
  - Claim details
  - Invoice attachments
- Create **pre-approval requests**
- View submitted claims and pre-approvals
- Track request status:
  - ✅ **Approved**
  - ❌ **Rejected** (with manager comments)
  - ⏳ **Pending**

---

### 🧑‍💼 Manager Features
- View all **pending claims** and **pre-approvals**
- Approve or reject requests
- Add **comments** while rejecting requests
- View approval and rejection **history**
- Dashboard overview:
  - Total pending claims
  - Total pending pre-approvals

---

## 🛠️ Tech Stack

### Frontend
- **Angular** (Standalone Components)
- **TypeScript**
- **Bootstrap** (UI Styling)

### Backend
- **ASP.NET Core Web API**
- **Entity Framework Core**

### Database
- **SQL Server**
